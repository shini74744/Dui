# 出口测速

面板 v26.9.57 起，在 **Xray 设置 → 出站规则 → 出口测速** 打开测速弹窗。也可直接点击某条出口操作菜单的“出口测速”，自动预选该出口；关闭后仍停留在原来的列表位置。

## 测量路径

所有测试均在面板服务器后台运行：**面板机器 → 所选出口 → 所选测速站**。浏览器只控制任务并查询结果，不使用用户手机或电脑的网络测试带宽。结果包含完整代理路径，不能单独代表面板与出口机器之间的物理链路带宽。

下载、上传和延迟均通过同一条选定出口及其显式代理链，失败不会切换到默认出口。[Cloudflare 的测试接口](https://github.com/cloudflare/speedtest#configuration)提供下载 GET、上传 POST 和零字节 HTTP 延迟请求。

## 使用方式

1. 保存出口设置，选择 1–10 个支持测速的出口。
2. 选择测速站点（默认 Cloudflare），再选择单线程，或多线程并自选 2–16 条并发，默认 4 条。
3. 点击“开始测速”。各出口依次测试，每个出口先下载、再上传，同时持续测量延迟。
4. 弹窗显示下载和上传的实时/平均速度、流量、时长和各自进度；Ping 显示最近值、平均、最低、最高、抖动及失败次数。

v26.9.58 起，下载开始前最多等待 45 秒，TLS 握手最多等待 30 秒；连接中会显示已等待时间和重试次数。临时网络错误、HTTP 429 或 5xx 会在等待预算内退避重试；HTTP 403 等明确拒绝及空响应会单独提示。收到首个下载数据字节后才开始计时，连接等待不计入采样时长。

每个方向最多采样 10 秒或传输 512 MiB；单个出口上传加下载最多约 1 GiB，不含协议开销。准备、建立连接另有超时，任务支持随时停止。测速会消耗出口流量并占用带宽；只有手动点击开始才会传输测速数据。

关闭弹窗不会停止后台任务；重新打开可以查看并停止同一任务。一次只允许一批任务，重复打开不会创建额外测速进程。列表位置、线程选择与最近结果保留；面板重启后内存中的结果清空。

## 测速站点

v26.9.58 起可选 **Cloudflare（默认）** 或 **自定义地址**。自定义下载地址必填，必须是 HTTP(S) 测试文件直链；上传地址选填，必须支持二进制 POST 并在接收完毕后返回 2xx；延迟地址选填，使用 GET，返回少量数据及 2xx 即可。无需上传或延迟时留空，对应项目显示“未测试”，不会暗中改用 Cloudflare。

不跟随 HTTP 重定向；请填写最终测速地址。URL 不支持内嵌账号密码或片段，每项最多 2048 字符。自定义请求保留原有查询参数。仅在点击开始时使用地址，不改变路由或探测配置。任务记录实际测速站点，修改下次测速选择不会改变已有结果的站点标注。旧 API 请求未提供站点时仍默认 Cloudflare。

## 结果含义

- 下载平均值按成功响应后实际收到的数据计算。
- 上传使用固定小缓冲区流式发送。平均值和已上传流量只统计收到成功响应的完整请求；实时值反映最近采样周期送入传输的数据，可能包含尚未确认的在途数据。
- Ping 是 HTTP 请求写出至收到首个响应字节的往返时间，约每秒检测一次；单次超时为 3 秒。它排除连接建立时间，不是 ICMP Ping。
- Ping 失败次数是 HTTP 探测失败，不能解释为网络层丢包率。抖动是相邻成功样本的绝对差均值。
- 上传、下载或延迟检测可以分别失败。部分连接失败会标记结果不完整；没有成功数据不会显示测速成功。
- 达到时间或流量上限才完成该方向采样。测速结束后实时速度显示“—”，保留最后一次 Ping 和汇总值。
- 测试站性能、并发业务、服务器性能及测量方法都会影响结果。

## 配置与资源隔离

只使用已保存的配置；存在未保存修改时禁用开始按钮。启动独立临时核心，使用带随机认证的本机代理端口，只复制所选出口、显式代理链及 DNS 配置，不复制业务入站、路由、探测任务、API 或日志。不重启业务核心，也不改变出口顺序。

黑洞、DNS、WireGuard 等需要专门网络接口的出口及不支持的代理链不参与测速。测试数据不写入文件、不在内存中累积；每个任务有流量、时间和并发上限。临时配置权限为 0600，结束后清除。接口要求登录，开始和停止还校验请求来源。

测速流量不计入业务核心的面板流量统计，但服务商和出口提供方仍可能计费。测速结果与保留 7 天的策略探测历史相互独立。电脑和手机使用同一弹窗，沿用面板主题、按钮和选择框样式。
