# 出站下载测速

面板 v26.9.52（待发布）在 **Xray 设置 → 出站规则 → 下载测速** 提供手动测速。也可在某条出口的操作菜单点击测速，预选该出口。

## 测量的是哪条链路

测速下载在面板服务器后台运行：**面板机器 → 所选出口 → Cloudflare 测速站**。浏览器只发送控制请求并查询进度，不通过用户手机或电脑下载测试数据。它测量完整代理路径的下载吞吐，包含出口到测速站的链路，不能单独代表面板到出口机器之间的物理带宽。测试站能力、并发业务和服务器性能也会影响结果。

使用 [Cloudflare 下载测试接口](https://github.com/cloudflare/speedtest#configuration)。测试站错误或下载失败会显示失败/部分完成，不自动改走默认出口或直连。

## 操作和结果

1. 先保存出口配置，然后选择 1–10 个出口。
2. 选择单线程（1 条下载连接），或多线程并自选 2–16 条并发，默认 4 条。
3. 点击开始测速。选中的多个出口依次执行，每个出口的测速连接并行下载。
4. 查看实时/平均速度（Mbps）、已下载流量（MiB）、时长和进度。可随时停止整批任务。

每个出口最多下载 10 秒或 512 MiB；准备和建立连接另有超时。到达流量上限会明确提示。测速会消耗出口流量并占用业务带宽，多线程更容易占满链路；它是手动操作，不会定时自动测速。

v26.9.53 起，结果区单独标明该次任务的时间及并发模式；结束后实时速度显示为“—”。进度表示实际采样时间，达到时间或流量上限才显示 100%；提前结束且有下载数据时显示黄色“不完整”提示。

平均速度按实际接收字节与首个成功响应后经过的时间计算。多线程的部分连接失败会标记结果不完整，不把错误响应当测速流量。实时速度按最近采样周期计算。

## 配置和业务隔离

- 只测试已保存的配置，未保存修改时禁用开始按钮。
- 从已安装核心启动独立临时进程，绑定带随机认证的本机代理端口；只复制所选出口及其显式代理链和 DNS 配置。
- 不复制业务入站、路由、API、探测任务或日志，不重启业务核心，不改变默认出站顺序。
- blocked、api 等黑洞出口、DNS、WireGuard 等需要专门网络接口处理的出口，以及不支持的代理链不参与本次下载测试。
- 一次只运行一批任务。关闭页面不会中止已开始的有限时任务；重新打开可查询同一任务，并可停止。
- 最后一次结果保存在面板进程内存中；新测试替换旧结果，面板重启后清空。它与保留 7 天的策略探测历史是不同功能。
- 测速流量经过独立核心，因此不计入业务核心的面板流量统计；服务商或出口提供方仍可能计费。
- 临时配置只允许当前系统用户读取，任务结束后销毁；接口要求面板登录，开始和停止还检查请求来源。

桌面使用多列结果卡片，手机自动单列；按钮、选择框、颜色沿用面板样式。主要操作跟随面板语言，未覆盖的说明使用英文回退。
