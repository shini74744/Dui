# 独立策略探测设置

最低延迟、最低负载、随机、轮询分别保存探测参数和观测结果。同一出口可以同时属于多个策略，各策略不会复用对方的延迟或存活结论。

面板中的字段名称和说明跟随所选的 13 种语言。配置 JSON 的核心字段名与出口标签保持原样。最低延迟提供地址、间隔和并发设置；其余三种提供地址、平均间隔、超时、样本数和本机连通性检查地址。高级 JSON 可保留额外字段。

打开页面不会迁移旧配置。编辑某个策略后，其配置写入顶层 strategyObservatory 下对应的策略名称；其他策略沿用原有设置。删除或切换负载均衡策略会同步更新对应的探测出口，暂未使用的策略保留参数但不探测。出站“同步保存”也覆盖这四组引用。

需要 DUI 核心 vx-26.5 或更新版本。旧核心不能保存独立探测配置，启用后也不能在面板中降级到不支持的核心。变更先进入页面草稿，点击页面“保存”后才生效。随机和轮询的故障排除仍需配置备用出口。

检测间隔不会改变既有连接的出口。最低负载使用探测延迟波动等指标，不读取 CPU、内存、在线人数或剩余带宽。


## 最近探测记录

DUI 26.9.45 与核心 vx-26.6 起可查看真实探测记录，按策略和出口筛选并分页。保存探测时间、成功/失败或本机网络不可用、单次延迟。旧版共享观察器产生的记录标记为共享，不伪装成四次独立探测；其历史可能出现在多个策略页。

面板每 5 秒从核心读取新增记录并去重，保存到 SQLite。保留最近 7 天、全局最多 100,000 条，超过时删除最旧记录。重启后已保存的记录仍在；页面刷新不会触发新探测，也不改变策略计算使用的样本数。只能从升级后开始收集。核心临时缓冲最多 4,096 条；面板长时间中断或极短探测间隔可能使缓冲溢出，界面会提示记录可能不完整。突然断电可能损失尚未收集的数秒数据。

查看入口使用面板已有登录验证；不记录探测 URL、凭据和用户连接地址。配置中的探测出口标签会显示。
