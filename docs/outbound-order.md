# 出站排序与默认出口

在 **Xray 设置 → 出站规则** 中，拖动每行前的手柄调整顺序。支持鼠标和触摸，拖到列表边缘可滚动；松开后更新当前草稿。按 Esc、取消手势或在列表外松开可取消拖动。

手柄聚焦时可使用上下方向键；行菜单也提供置顶、上移、下移、置底。最后点击页面“保存”才会写入配置并生效。

## 首个出站有什么作用

一条连接未命中任何路由规则时，Xray 使用出站列表中的第一个出站作为默认出口。

例如：

| 出站顺序 | 未命中任何路由的新连接 |
| --- | --- |
| `direct`（freedom）、`HK-A`、`JP-A` | 使用直连 |
| `HK-A`、`direct`（freedom）、`JP-A` | 使用香港出站 HK-A |

判断依据是实际排序及出站协议，不是标签恰好叫 `direct`。需要默认直连时，把实际的 `freedom/direct` 出站放在第一位。内部黑名单出口不显示为可拖动行，也不会因置顶变成默认出口。

## 排序会影响哪些配置

已有路由、负载均衡和探测设置按标签引用出站，不会因拖动排序被重写。出站的协议、连接参数、未知字段和待同步改名记录保持原样。

改名后需要同步其他规则的标签引用时，使用 [出站同步保存](outbound-reference-sync.md)。普通排序不需要改写这些标签。

出站排序和路由规则顺序是两回事：

- 路由规则从上往下判断，命中后按该规则选择出口。
- 没有命中路由规则时，才使用出站列表第一项。
- 内网或 BitTorrent 拦截规则同样按顺序匹配。需要让拦截规则生效时，应避免前面的宽泛放行规则先行匹配。
- 内部 API 规则有面板通信用途，不应因为它属于默认规则就随意删除。
