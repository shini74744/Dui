# 出站排序

在 Xray 设置的出站规则列表中，拖动每行前的手柄调整顺序。支持鼠标和触摸，拖到列表边缘可滚动；松开后更新当前草稿。按 Esc、取消手势或在列表外松开可取消拖动。手柄聚焦时可使用上下方向键，行菜单也可置顶、上移、下移、置底。

点击页面“保存”才会写入配置并生效。列表首个出站是未命中路由时的默认出口；排序可能改变默认出口。已有路由、负载均衡和探测设置按标签引用出站，不会因排序被重写。出站的协议、连接参数和未知字段保持原样，待同步改名记录仍按标签关联。内部黑名单出口不显示为可拖动行，也不会因置顶变成默认出口。

- scripts/test-outbound-order-integration.py：隔离面板中的保存、读取、运行配置顺序和引用保留。
